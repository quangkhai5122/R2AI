# G3A v1 bundle

This directory is generated by scripts/65_g3a_build.py from the canonical
store and then sealed with g3a_hard_reviews.jsonl.

Authoritative files:

- g3a_manifest.json: provenance, counts, leakage audit, and file hashes.
- g3a_questions.jsonl: all 144 offline questions.
- g3a_gold.jsonl: answer plus document/table/cell provenance.
- g3a_oracle_codegen.jsonl: evaluator/replay contract check only.
- g3a_hard_review_queue.jsonl: evidence shown during manual review.
- g3a_hard_reviews.jsonl: hash-bound review decisions.

These ids and questions are synthetic. Never upload an artifact built from this
directory to the competition leaderboard.
